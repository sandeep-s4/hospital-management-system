# Hospital Management System

A simple web-based Hospital Management System built using Java, Spring Boot, MySQL and Thymeleaf.

## Features

### Admin

- Admin login with username, password, and CAPTCHA
- Default admin account
- Add new patients
- Edit patient details
- Delete patients
- View all patients in a table

### Patient

- Patient login with username, password, and CAPTCHA
- Patient accounts are created by the admin
- View personal patient details
- View DOB, mobile number, address, total amount, paid amount, and balance

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- BCrypt
- HTML, CSS
- Maven
